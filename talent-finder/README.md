# Talent Finder

A voice interview for job seekers that finds hidden, transferable talents and turns them into resume bullets.

**Privacy:** nothing is saved. The transcript lives only in the browser tab.

## Run it

Requires Node 20+.

```bash
cd talent-finder
npm install
npm start
```

Open http://localhost:3000 in Chrome, Edge, or Safari (voice). Any browser works in typing mode.
